为什么做"语音"而不是再加一个文字 Agent？

能力亮点（写给技术面试官看）

  • 工具调用可视化：Agent 能调用计算器 / 时间 / 天气 / 搜索，界面实时展示"它调了什么"，体现对 Function Calling / MCP 的理解。
  • RAG 知识库：粘贴一段资料，Agent 基于它回答（本地 TF-IDF 检索，无需外部向量库）。
  • 真时双向语音：国内 MiniMax Realtime 适配，无需翻墙即可真·实时语音（需密钥）。
  • 密钥安全：所有模型密钥只在服务端，浏览器永远拿不到，通过 ephemeral token / 代理转发。
  • 可观测：实时显示首包延迟与对话时长，把语音 Agent 最关键的延迟指标显性化。

产品取舍（PM 视角）

可演示性优先

真时模型要密钥、要网络、要麦克风。所以做了"模拟模式"用浏览器能力零成本复现完整 UX，保证任何时候都能演示。

国内直连

默认对接 DeepSeek 兼容端点，普通大陆网络即可跑，不依赖代理。

不止文档

项目可运行、可开源、有真实交互，拒绝"只写 PRD"的同质化。
